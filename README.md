# דיימונד כנרת — לוח תנאי גלישה

לוח מידע מאוחד לגלישת קייט בדיימונד (כנרת): רמזור סע/לא-לגלוש, תחזית רוח יומית, מפת תחנות WRF ומפת רוח חי מ-IMS. קובץ HTML יחיד (`index.html`), בלי build step — מיועד להטמעה כ-embed ב-Google Sites או לאירוח ישיר ב-GitHub Pages.

## רכיבים

- **רמזור (`#go`)** — מחליט "סע לגלוש" / "לא לגלוש" לפי כיוון רוח בים התיכון וגאסט WRF בדיימונד, ומציג גם אחוז סיכוי לגלישה שמושפע מהפרש טמפ' צמח–אבני איתן, רוח בקרית ים וחום אזורי.
- **תחזית רוח (`#fc`)** — טבלת גאסט/כיוון/חלון-רוח ל-5 ספוטים (דיימונד, בצת, קרית ים, נחשולים, בית ינאי), מקור WRF-1km.
- **מפת תחנות WRF (`#wrf`)** — מפת Leaflet עם ~30 תחנות (מודל ו/או תצפית), כולל גרף וטבלת windguru לכל תחנה.
- **רוח חיה (`#wind`)** — מפת IMS live, גאסט/כיוון עדכני לתחנות חוף וכנרת, עם גרף גאסטים יומי בלחיצה על תחנה.

## ארכיטקטורה

```
דפדפן (index.html)  →  Google Apps Script (proxy + IMS_TOKEN)  →  IMS Envista API
                     →  Google Drive (קבצי CSV מ-WRF-1km)
                     →  Open-Meteo (כיוון/עוצמת רוח בים, נוכחי + ארכיון)
```

הדפדפן לא פונה ישירות ל-IMS (דורש token) — כל קריאות IMS עוברות דרך Apps Script אחד ששומר את ה-token בצד השרת. קבצי ה-WRF (`18z_1km_<spot>.csv`) יושבים בתיקיית Drive וגם הם מוגשים דרך אותו Apps Script.

**הערה:** בקוד יש היום כמה URL של `/exec` שונים (`APPS_SCRIPT_URL` ב-4 המקומות, ועוד `HISTORY_URL`) — כולם אמורים להצביע על אותו פרויקט Apps Script, סתם דיפלוימנטים שונים שנוצרו בזמנים שונים. אפשר לאחד לדיפלוימנט אחד אם רוצים לנקות.

## הגדרת Apps Script

1. פרויקט Apps Script אחד עם:
   - `IMS_TOKEN` — טוקן API של שירות המטאורולוגי (IMS Envista).
   - `ROOT_FOLDER_ID` — תיקיית Drive שמכילה (בכל מבנה עומק) תיקייה בשם `csv` עם קבצי ה-WRF.
   - `IMS_REGION` — מזהה אזור ל-endpoint `?list=`.
2. `doGet(e)` תומך ב-endpoints:
   - `?wind=<id1,id2,...>` — קריאה אחרונה (latest) לכמה תחנות, מחזיר `{ws, gust, dir, time}`.
   - `?gustday=<id>` — גאסטים 10 דק' להיום עבור תחנה אחת.
   - `?wsmax10=1` — ממוצע גאסט במרום גולן (06:40–07:40) לרמז הבוקר.
   - `?ims=zemah|avnei` — טמפ' ב-10:30 (בפועל 09:30 בחותמת IMS, ר' "הערת שעון" למטה) לצמח/אבני איתן.
   - `?history=<id>&from=...&to=...` — טווח תאריכים חופשי לכל תחנה (טמפ'/רוח/גאסט/כיוון), משמש לבקטסטים ולממוצע חום אזורי.
   - `?name=<filename>[&date=YYYY-MM-DD]` — מגיש קובץ CSV מתיקיית `csv`; עם `date`, מגיש מהארכיון (`csv/archive/`).
   - `?windstations=1`, `?times=1`, `?list=1` — עזר/דיבוג.
3. טריגר יומי (`createDailyArchiveTrigger`, רץ פעם אחת ידנית מה-editor) מריץ כל בוקר ב-07:00 את `archiveWrfCsvs_`, ששומר עותק מתוארך של כל קובץ WRF בתיקיית `csv/archive/` — כדי שיהיה אפשר לבדוק בעתיד את דיוק התחזית מול מה שבאמת קרה.

## הערת שעון IMS

ה-API של IMS מחזיר את החותמת בשעון חורף קבוע (LST) גם בקיץ, כשה-offset בחותמת (`+03:00`/`+02:00`) לא תמיד תואם בפועל. הפונקציה `imsLocalTime()` מתקנת את זה (מוסיפה שעה כש-offset הוא `+03:00`). כל מקום שמציג זמן ממקור IMS עובר דרך הפונקציה הזו — אם מוסיפים תצוגת זמן חדשה ממקור IMS, חשוב להשתמש בה ולא ב-`.substr(11,5)` גולמי.

## יחידות

IMS מחזיר `WS`/`WSmax` ב-מ/ש (m/s), לא בקשרים. כל תצוגה משתמשת ב-`msToKts()` (×1.943844) להמרה. Open-Meteo ו-WRF כבר מגיעים בקשרים (`wind_speed_unit=kn`).

## פרמטרים של הרמזור (`CFG` ב-`initGo`)

| פרמטר | משמעות |
|---|---|
| `favDir` | טווח כיוון נוח בים התיכון (מעלות מטאורולוגיות) |
| `gustMinKts` | סף גאסט WRF בדיימונד להחלטת "סע לגלוש" |
| `tempDiffMin` | סף הפרש טמפ' צמח-אבני איתן — **משפיע רק על אחוז הסיכוי**, לא חוסם את הרמזור |
| `coastalWindow`, `coastalMinGustKts`, `coastalPenalty` | בדיקת גאסט בקרית ים 10:00-14:00; אם חלש, מוריד את הסיכוי |
| `heatBaselineDays`, `heatDeltaMin`, `heatPenalty` | חום אזורי חריג (צמח מול ממוצע 7 ימים) — מוריד את הסיכוי |
| `ronen` | טבלת הפרש-טמפ' → אחוז סיכוי (fit לפרבולה ב-`fitQuad`) |

הרמזור עצמו (ירוק/אדום) נקבע היום רק לפי **כיוון רוח בים** (עד 13:00, כי לוקח ~4 שעות להגיע) ו**גאסט WRF בדיימונד**. שאר הבדיקות (הפרש טמפ', רוח בקרית ים, חום אזורי) הן modifiers של אחוז הסיכוי בלבד ולא חוסמות.

## בקטסט

בוצע בקטסט חלקי (יולי 2026) מול גאסט אמיתי בלב כנרת (IMS): דיוק 71% על כיוון+הפרש-טמפ' בלבד. לא ניתן היה לבדוק את תנאי ה-WRF (גאסט דיימונד, קרית ים) כי לקבצים לא היה ארכיון — מה שהטריגר היומי (מעלה) פותר מכאן ואילך. הממצא המרכזי: הפרש הטמפ' מתאם חלש (r≈0.2) עם התוצאה בפועל, ולכן הוצא משער חוסם והפך ל-modifier.

## הטמעה

- **Google Sites:** Insert → Embed → Embed code, הדבקת כל תוכן `index.html`.
- **GitHub Pages:** להעלות את `index.html` לריפו, להפעיל Pages על הענף/תיקייה הרלוונטית.
